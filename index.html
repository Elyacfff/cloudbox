📖 使用指南

🚀 快速开始

  1. 在首页填写 GitHub Token 并保存
  2. 拖拽文件到上传区域，或点击选择文件
  3. 文件自动上传到 GitHub 仓库
  4. 生成永久 CDN 链接，一键复制分享

✨ 功能特性

  • 📤 拖拽上传 - 支持批量拖拽、粘贴截图
  • 👁️ 文件预览 - 图片、视频、代码在线预览
  • 📋 批量操作 - 批量复制、下载、删除
  • 🔗 短链接 - 生成短链接方便分享
  • 📱 二维码 - 为任意链接生成二维码
  • 🗜️ 图片压缩 - 压缩图片节省空间
  • 🌓 主题切换 - 暗黑/亮色模式
  • 🔍 文件搜索 - 快速查找文件

🔗 链接格式

文件通过 jsDelivr CDN 加速，永久有效：

https://cdn.jsdelivr.net/gh/{用户名}/{仓库名}@main/{文件路径}

⚠️ 注意事项

  • 单文件最大 25MB（GitHub限制）
  • 每个仓库免费额度 2GB
  • 建议定期清理不需要的文件
  • Token仅保存在本地浏览器
