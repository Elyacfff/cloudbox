🚀 快速开始

1

获取 GitHub Token

访问 GitHub Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token

勾选 repo 权限，生成后复制 Token

2

创建存储仓库

在 GitHub 上创建一个新的 Public 仓库，名称如 cloudbox-files

3

填写配置

在首页填写你的 GitHub 用户名、仓库名和 Token，点击保存

4

上传文件

拖拽文件到上传区域，自动上传到 GitHub 仓库并生成永久 CDN 链接

🔗 链接格式

文件上传后，通过 jsDelivr CDN 生成永久访问链接：

https://cdn.jsdelivr.net/gh/{用户名}/{仓库名}@main/{文件路径}
